Weight And Liberty-based Recommendation Utility System

Recommendations your users can tune.

WALRUS is a recommendation engine you adapt to any content with a YAML schema. The platform decides what can be weighted; the end user decides how much, and every result says why it was shown.

How it works

Three steps to a tunable feed

01

Describe your data

Push a schema.yml with your entities, interactions, signals, knobs and hard constraints. No code change, no rebuild.

02

Send events

Your backend ingests entities and interactions through the API. WALRUS never reads your database.

03

Serve a ranked feed

Ask for recommend(user, knobs) and get ids, scores and the reasons behind them. Your app hydrates and renders.

Why WALRUS

Control and explanation, built in

Most engines optimise engagement with weights only the operator can see. WALRUS exposes a few curated knobs to the end user and explains each result with the same signal breakdown that produced it.

That also lines up with Article 27 of the EU Digital Services Act, which asks large platforms to explain their recommender parameters and let users influence them.

  • Two-layer control. The author defines the signals; the user moves the knobs.
  • Instant re-ranking. Candidates do not depend on weights, so a slider change re-scores in memory.
  • Explainable. Every item carries a per-signal breakdown.
  • Hard constraints. Exclusions apply before scoring and no knob can override them.
  • Content-agnostic. Feeds, marketplaces and streaming from one engine.
  • Multi-tenant. Self-host it or run it as a hosted API.

The contract

The schema is the integration

YAML is the only format. A trimmed example:

# schema.yml
version: 1

entities:
  user:
    key: id
    attributes:
      city:     { type: categorical }
  listing:
    key: id
    attributes:
      category: { type: categorical }
      price:    { type: float }
      tags:     { type: set, of: string }
      status:   { type: categorical }
# ...interactions, signals, knobs and constraints follow

Get started

Run it, then push a schema

WALRUS needs Neo4j and an admin key. The repository has the engine, the SDK and the integration guide.
